绘约 v1.3.2 · 自动兼容版

酒馆扩展管理中更新绘约后刷新，确认入口显示 v1.3.2。
打开「我的 → 设置、AI 接口与存档」。
在需要使用独立站点的服务中：填写站点 URL 和该站 API Key → 点击「拉取模型并连接」→ 选择模型 → 保存设置。
不用选择站点预设，也不用设置协议、路径或兼容参数。
私信、提示词和生图可分别使用不同站点；密钥仅保留在当前页面内存，刷新后需重新输入。
旧设置继续可用，升级不会清除存档。

在线安装：酒馆「扩展 → 安装扩展」，填写 https://github.com/yuh123776-cyber/- 。
安装后刷新页面。不需要 npm install 或编译。
自动读取模型列表不会自动生图；没有模型列表接口的 NAI 站点会显示参考模型并明确提示尚未验证连接。
已知站点与限制见 README.md。
