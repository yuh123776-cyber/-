绘约 v1.5.0 · 生图预设、角色私信与企划回复

在酒馆扩展管理中更新原有绘约，然后刷新页面，确认入口显示 v1.5.0。
原仓库地址：https://github.com/yuh123776-cyber/-
新安装仍可在「扩展 → 安装扩展」填写这个地址，不需要 npm install 或编译。
更新保留存档、原图与已保存的多套 API 配置和密钥，不要清理网站数据。

我的 → 设置、AI 接口与存档 → 顶部导航：
1. 接口与存档：原有 URL、密钥、模型、多套 API 配置。
2. 生图规则与预设：全局正反向、草稿专用正反向、规范、附加指令和自填推理提示位置。
   预设优先级：草稿专用非空 → 单画师非空 → 全局默认，正反向分别处理。
3. 私信与剧情互动：新版对话预设、统一 AI / 条目选择、甲方头像库、自定义气泡。
   统一选择影响企划答复时间、接受 / 拒绝、理由、首次私信和甲方开场。

稿件上的“重 roll”或留空修改只换种子，不请求文本模型；填写修改意见才重新生成提示词。
两者仍请求生图服务，旧图保留为原版本。所有图片可从“我的 → 我的稿件”按身份查看。
企划邀请先等待答复，接受后先私信；正文明确结果优先，不自动下单付款。
定价规则在编辑画师或自己的画师资料里填写，例如“商用 * 2”“某IP同人打95折”。
完整功能、限制与测试说明见 README.md / TESTING.md。

绘约 v1.4.0 · 保存密钥与多套 API 配置

酒馆扩展管理中更新绘约后刷新，确认入口显示 v1.4.0。
打开「我的 → 设置、AI 接口与存档」。
填写 URL 和密钥 → 拉取并选择模型 → 保存设置，之后会在当前浏览器记住密钥。
要保存更多 API，点击对应服务下的「新增配置」再填写并保存。
选择「已保存的 API」后点击保存设置，即可切换到该配置；名称可自定义，也可留空自动命名。
Key 留空保留已保存密钥；「清除密钥」只移除该配置的密钥，「删除配置」移除整套配置。
API 配置库由当前浏览器的绘约世界共用，私信、提示词、生图各自选择；普通存档导出不包含密钥，配置库不跨设备同步。
旧版只在内存中的密钥需在新版保存一次。升级不会清除剧情存档或原图。

在线安装：酒馆「扩展 → 安装扩展」，填写 https://github.com/yuh123776-cyber/- 。
不需要 npm install 或编译。接口兼容由插件自动处理。
