绘约 v1.2.2 · API 模型列表选择

不需要 npm install 或编译。

绘约 · SillyTavern 扩展 v1.2.2

推荐：酒馆内在线安装（SillyTavern 1.19.0 及以上）
1. 打开「扩展」→「安装扩展」。
2. 输入 https://github.com/yuh123776-cyber/- 并安装。
3. 刷新酒馆页面，在扩展管理中确认已启用。
4. 点击右下角「✿ 绘约」，或输入 /huiyue。

不需要酒馆助手、npm install 或编译。
安装后可以直接体验本地模拟、上传与文字稿；AI 功能需要配置可用模型。

手动安装备用：将本目录所有文件放入
SillyTavern/public/scripts/extensions/third-party/huiyue/
确保 manifest.json 直接在 huiyue 内，不要再套一层文件夹。
若手机访问电脑上的酒馆，只需在电脑的酒馆服务端安装。
请勿同时在线安装和手动安装两份相同扩展。

更新：在扩展管理中检查更新，更新后刷新页面。
存档保存在当前浏览器，建议定期导出完整存档；不同设备不自动同步。
新增：魔法棒入口、花翼小绘悬浮图标、画师注销、剧情账户扣款充值、国家/地区、动态评论与点赞名单。
剧情资产的 AI 判断和正文同步仅使用酒馆当前文本模型；首次建账后保存余额，后续按正文与充值流水增减。
详细配置与限制见 README.md。

新设置：提示词 AI 附加指令、生图 AI 附加指令、仅绘约私信生效的对话预设。手机悬浮入口已加强弹窗层级和可视区域适配。

悬浮图标可按住拖动，轻点打开。聊天新增图片及自定义表情包；给表情命名后，AI 可按名称选择发送。普通图片通过文字说明参与对话。

修复：模拟客户改为独立的一对一私信；可确认归属的旧记录自动分配，未知旧记录保留只读。手机拖动增加直接触摸处理和宿主事件拦截兼容。
