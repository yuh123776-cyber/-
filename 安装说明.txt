绘约 v1.4.0 · 保存密钥与多套 API 配置

酒馆扩展管理中更新绘约后刷新，确认入口显示 v1.4.0。
打开「我的 → 设置、AI 接口与存档」。
填写 URL 和密钥 → 拉取并选择模型 → 保存设置，之后会在当前浏览器记住密钥。
要保存更多 API，点击对应服务下的「新增配置」再填写并保存。
选择「已保存的 API」后点击保存设置，即可切换到该配置；名称可自定义，也可留空自动命名。
Key 留空保留已保存密钥；「清除密钥」只移除该配置的密钥，「删除配置」移除整套配置。
API 配置库由当前浏览器的绘约世界共用，私信、提示词、生图各自选择；普通存档导出不包含密钥，配置库不跨设备同步。
旧版只在内存中的密钥需在新版保存一次。升级不会清除剧情存档或原图。

在线安装：酒馆「扩展 → 安装扩展」，填写 https://github.com/yuh123776-cyber/- 。
不需要 npm install 或编译。接口兼容由插件自动处理。
